# 🌸 Portfólio — Sophia Oliveira

Meu portfólio pessoal como **Front-End Developer**, desenvolvido para apresentar minha trajetória, habilidades e os principais projetos que venho construindo na área de desenvolvimento web.

Esta é uma nova versão do meu portfólio, criada com uma identidade visual mais pessoal e com foco em uma experiência moderna, responsiva e interativa.

## Preview

![Preview do Portfólio](./src/assets/preview.jpeg)

## Sobre o projeto

O objetivo deste projeto é reunir em um único lugar um pouco sobre mim, minhas tecnologias, formação e projetos.

Durante o desenvolvimento, busquei trabalhar conceitos como:

- Componentização com React
- Responsividade
- Animações e microinterações
- Navegação entre páginas
- Organização e reutilização de componentes
- UI/UX
- Identidade visual própria

## Tecnologias

O projeto foi desenvolvido utilizando:

- **React**
- **JavaScript**
- **Tailwind CSS**
- **React Router**
- **React Icons**
- **Vite**
- **Git & GitHub**

## Funcionalidades

- Apresentação profissional
- Seção de tecnologias
- Projetos em destaque
- Página individual para cada projeto
- Galeria de imagens
- Navegação entre projetos
- Links para GitHub e demonstrações
- Animações e elementos interativos
- Layout responsivo para diferentes dispositivos


## Aprendizados

Durante o desenvolvimento desta nova versão do portfólio, pude praticar e aprofundar conhecimentos em:
